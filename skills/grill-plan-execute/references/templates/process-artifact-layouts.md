# 过程文件版式（环境文档 / 发现台账 / Workflow Resume）

自有产物版式，不含上游正文。字段与规则的语义在 `SKILL.md` 对应小节定义一次，本文件只管排版。

**这三份文件里都不要抄写执行期义务。** 义务的唯一语义源是 `execution-contract.md`，它随每份计划送达执行会话；在这里再抄一份就是第五处副本，必漂。

`docs/engineering-discipline/context/YYYY-MM-DD-<topic>-environment.md`

```

```

|------|------------|--------------------|------|--------------------|------|
| 2026-10-16 | M1 | 把路径当内容 grep 会恒 0 匹配 = 假通过 | 坑 | 全部 | 生效 |

类型：`环境事实`／`契约口径`／`术语`／`决策`／`坑`。状态：`生效`／`promoted→目标文件`／`superseded→新条目`／`stale@日期`。只追加，推翻时两行都留着。

## Workflow Resume

写在 Context Brief 末尾，批量更新，不另建平行进度表。

```
## Workflow Resume
- 下一阶段：<> ｜ 用户确认的复杂度：<> ｜ 当前里程碑：<> ｜ DAG 已锁定：是/否 ｜ 执行方式已选择：<> 或 待定
- 路径：模板来源 / 词汇表 / 决策记录 / 假设登记表 / locked 决策索引 / 环境文档 / 发现台账 / 当前草稿或就绪计划及状态 / 复杂路径 state.md
- 宿主能力与锚点：环境文档建立前记在这里，建立后只留一句"见环境文档#宿主能力与环境事实"
- 未决阻塞：<> ｜ 已接受的非阻塞假设及复核时点：<>
- 代码事实基线：HEAD <> ｜ 未提交改动范围 <>
- 当前里程碑验证结果与证据路径：<>
```

里程碑状态以上游 `state.md` 为准，不复制整张 DAG 或评审日志；执行进度以计划文档的 Task 勾选为准，不在这里维护第二份。
