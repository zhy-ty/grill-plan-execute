# 规划登记表版式（假设登记表 + `locked` 决策索引）

自有产物版式，不含上游正文。字段语义在 `SKILL.md` Phase 1 定义，本文件只管排版，不重复定义语义。两张表都放在 Context Brief 里（或紧邻其末尾的 Workflow Resume 之前），随主题批量更新。

## 假设登记表

非阻塞假设集中放这里，不散在访谈记录里。

```
| 编号 | 假设内容 | 受影响里程碑 | 最迟复核时点 | 状态 |
|------|----------|--------------|--------------|------|
| A-01 | <一句话假设> | M2, M5 | Phase 4 开工前 | 待复核 |
```

状态取值：`待复核`／`已验证`／`已证伪`。证伪时不删行，改状态并在发现台账追加一条。

复核触发点固定三处：**Phase 3 规划前**（假设会影响里程碑划分时）、**Phase 4 开工前**、**Phase 5 里程碑收尾**。不写"定期"。

索引只是查询入口；**结论详情的唯一来源是原决策记录**，不在这里复制论证。

```
| ID | 状态 | 一句话结论 | 出处 | 影响哪些里程碑 |
|----|------|------------|------|----------------|
| D-07 | locked | <用户拍板的结论> | 决策记录#<编号> | M3, M_final |
| D-09 | deferred-with-criteria | <授权执行期按判据自决的范围> | 决策记录#<编号> | M4 |
```

用途有三处：Phase 3 批评者的输入、Phase 4 写计划时填 `Key Decisions` 的来源、Phase 5 提问前的第一个查询点。
